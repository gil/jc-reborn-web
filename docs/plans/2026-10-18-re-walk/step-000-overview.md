**Goal:** Check every walk function of the original (`1018:0000`..`1018:03ea`) against our engine, replace `src/walk/` (a jc_reborn port with a depth-first path search and `Math.random`) with a literal port of the original's route tables and walk step, wire it into the story the way `1018:06bf` calls it, and close OQ-25.

**Architecture:** The original has no path search. Each pair of spots (from, to) has a *route*: for every spot Johnny can be on, a list of (segment, percent) choices. A *segment* is a list of frames that walks Johnny from one spot to another, with a start heading, an end heading, and an end spot. Two *turn sets* per spot (standing, walking) hold one frame per heading. Each call of the walk step (`1018:0094`), when its 4-tick frame delay has run out, picks a segment, turns Johnny one heading toward it, or moves him one frame along it; then, on every call, it draws the current frame, redraws the palm trunk over him (`1010:1551` mode 0), and adds three dirty rects. The port lives in `src/walk/walk-tables.ts` (tables generated from the binary), `src/walk/walk.ts` (the functions), and `src/engine/timers.ts` (the frame delay). A Unicorn harness runs the original walk step on 36 cases and a data test compares its trace with ours.

**Tech Stack:** TypeScript + Vitest (Node 24, pnpm), Python 3.11 + `unicorn==2.1.4` in `re/.venv`, Ghidra 12.1.4 at `$GHIDRA_INSTALL_DIR` (`/Applications/ghidra`), exports in `re/out/`.

Read `docs/re/README.md` and `scripts/re/unicorn/README.md` once before starting. `docs/re/island.md` is the model for the findings file this chunk writes (`docs/re/walk.md`).

The current `src/walk/` is jc_reborn's design: spots 0..5, a depth-first search over a connection matrix (`calcpath.ts`) that picks a path with `Math.random`, frame data with "bookmarks" (`walk-data.ts`), a 6-tick frame delay, an 80-tick rest on arrival, the palm tree sprites 12 and 13 drawn when Johnny is "behind the tree", and dirty rects 2 pixels too tall. ## Binary facts (first reading, 2026-10-18)

These come from reading the export and dumping the data segment during planning. Step 1 confirms or corrects each and writes the confirmed version as a finding. Address format `ssss:oooo`; `1068` is the auto data segment (DS). Far cdecl: first argument at `[BP+6]`, caller pops.

### Globals (`1068`, all 0 in the data segment at load)

| Address | Meaning |
| --- | --- |
| `30d2` | JOHNWALK.BMP bitmap list (shared with the TTM: `1058:079f`, `1050:080c`) |
| `30e2` / `30de` | Johnny's spot (1..6) / heading (0..7); also written by the story (`1018:0540`, `1018:06bf`) |
| `30e0` / `30dc` | target spot / target heading (-1 = no heading wanted); written by `1018:0b46`, `1018:0000`, `1018:0094` |
| `30d0` | the route list being walked (0 = none) |
| `30ce` | the next record of the segment being walked (0 = none) |
| `30c6` | the frame record drawn on every call (0 = none yet) |
| `30c8` | wanted heading |
| `30cc` / `30ca` | end heading / end spot of the segment being walked |
| `30d4` | frame delay, counted down by the clock `1008:16c2` |

### Tables (one block, `1068:02e1`..`165f`)

- `1068:02de + 3s`, `s` = 1..34: segment `s` as three signed bytes: start heading, end heading, end spot. Segments 5, 6, 9, 10, 16, 17, 21, 22, 27, 28, 33, 34 are (0, 0, 0): they are the turn sets. `02de`..`02e0` (segment 0) is (0, 0, 0) and lies just before the block.
- `1068:0347 + spot` (spot 0..6): standing turn set of each spot `[0, 6, 10, 17, 22, 28, 34]`. `1068:034e + spot`: walking turn set `[0, 5, 9, 16, 21, 27, 33]`.
- `1068:0355`: `JOHNWALK.BMP` and a 0 byte.
- `1068:0362`..`0aa1`: 30 route lists, one per (from, to) with from ≠ to, in from-major order (1,2), (1,3), ..., (6,5). Each list: for spot 1..6 in order, the marker word `-spot` followed by (segment, percent) word pairs; then `-7`. The group of the route's own target spot is the single pair (0, 0).
- `1068:0aa2`..`0ae9`: route table, the word for (from, to) at `0x0a94 + 12 × from + 2 × to` (from, to 1..6); 0 when from = to.
- `1068:0aea`..`165f`: 34 frame lists in segment order (first at `0aea`, last ends at `1660`). Records of three words: sprite index (bit `0x8000` = mirrored), x, y (relative to the island offset `1068:30c4` / `30c2`). Each list ends with a (0, 0, 0) record. Turn sets have 8 records; record `h` faces heading `h`.
- Seen in the dump: the route (1, 5) group of spot 1 is `(4, 16) (4, 17) (3, 34) (2, 33) (1, 25) (1, 25)`; the first four reach 100, so the direct segment 1 (spot 1 to spot 5) is never picked there.

### Functions

- `1018:0000` (`walk_loadJohnWalkBmp`, called once by `1008:143c`): when `30d2` is 0, loads `JOHNWALK.BMP` (`1030:124a`) with `1068:4106 = 1` (build mirrored copies), then sets `30e0 = 1`, `30e2 = 1`, `30de = 0`. Returns whether `30d2` is set.
- `1018:004d` (called by `1008:157b`): frees `30d2` and clears it.
- `1018:0074` (near-called by `1018:06bf` at `1018:0771`, an idle entry's first step): `30d0 = 0`, `30ce = 0`, `30c8 = 30de`.
- `1018:03ac(from, to)`: 0 when either is 0; else the route table word.
- `1018:03ea(id)`: the address of segment `id`'s frame list for 1..34 (`0aea`, `0b50`, `0bce`, ...); 0 otherwise.
- `1018:0094` (near-called by `1018:06bf` at `1018:073a`, walking to an entry's start, and `1018:0776`, every idle step). When the delay `30d4` is 0:
  1. No route and spot ≠ target: route = `1018:03ac(spot, target)`.
  2. A route and no segment: find the marker `-spot` in the route. Not found (reached `-7`): return at once (nothing drawn, delay unchanged). Else `r = rand % 100` (unsigned `DIV`); walk the pairs: `r -= percent`, go on to the next pair while `r > 0` (signed `JG`); the segment is that pair's first word. `30ce = 1018:03ea(segment)`; `30c8` = its start heading, `30cc` = its end heading, `30ca` = its end spot. When `30ce` is 0: Johnny is put at the end spot and heading at once, and the route is cleared when that is the target.
  3. Target heading set (`30dc ≠ -1`), spot = target, heading = wanted: when wanted = target heading, the frame is the standing turn set of the spot at the heading, and `30dc = -1`; else wanted = target heading.
  4. Heading ≠ wanted: `d = heading - wanted`; turn = random (`rand & 1`: 0 → +1, 1 → -1) when `d = ±4`; -1 when `d < -4` or `0 < d < 4`; +1 otherwise. `heading = (heading + turn) & 7`. The frame is the turn set of the spot (standing when spot = target, else walking) at the new heading.
  5. A segment and heading = wanted: the frame is the segment's next record; the record moves on; when the record after it is (0, 0, 0): spot = `30ca`, heading = `30cc`, no segment, and the route is cleared when spot = target.

  Then, on every call (delay or not), when a frame is set: image = JOHNWALK `[word & 0x7fff]`, flags 2 when bit `0x8000` is set else 0, `x = 30c4 + x`, `y = 30c2 + y`; `1038:0ae4(image, x, y, flags)` on the current target; `1010:1551(image, x, y)` (mode `1068:2e78 = 0`: only the palm trunk, BACKGRND sprite 13); `1060:007e(x, y, w, h, 1, ...)` three times with the image's width and height: (B → A, age 0), (B → A, age 1), (C → B, age 0) (`1068:1eb0` = C, `1eb2` = B, `1eb4` = A); then `30d4 = 4`.
- Story side (chunk 7, verified): `1018:0b46(spot, heading)` stores `30e0 = spot` unless 0 and `30dc = heading` unless -1, and says whether Johnny is there. `1018:06bf` calls `1018:0094` while an entry is pending and Johnny is not at its start, calls `1018:0074` on an idle entry's first step and `1018:0094` on every idle step, and never calls the walk during an ADS entry. `1018:0540` puts Johnny at the first entry's start spot and heading without touching the walk state.
- Timing: one story step per 50 ms, a clock tick per 16 ms, so the 4-tick delay runs out on every other step most of the time: a new frame about every 100 ms.

## Trace format (steps 2 and 4)

Step 2 writes `re/fixtures/walk/traces.tsv` from the original; step 4 builds the same rows from our port. Header: `case	beat	event	values`. `values` are joined with one space. Surfaces: 0 = A, 1 = B, 2 = C.

Each case `k` (0..35) is a fresh emulator:

1. `1010:0136` once with nothing set (it only loads BACKGRND and MRAFT).
2. Globals: mode `30b2 = 0`, place `30be = 0xffff`, low tide `30c0 = k % 2`, still `30b0 = 0`, no raft `30ae = 0`, holiday shown `30b4 = 1`, holiday `30ba = 0`, slot `30b8 = 0`, Background `00b6`, Clouds `00b8`, Waves `00ba` = 1, speed `30bc = 0`, NumDays `2d9b = 1`; the clip off with rect `(0, 0, 639, 479)`.
3. Discard `1009 × k` random values (`1018:1eb6`); the `1060:04b2` call counter starts at 0; `1010:0136` again (places the island).
4. `30d2 = 0`, then `1018:0000` (loads JOHNWALK, sets spot 1, heading 0, target 1).
5. Johnny's spot `30e2 = 1 + floor(k / 6)`, heading `30de = k % 8`. Every row so far is dropped; write one `state` row with beat `-1`.
6. Beats are numbered from 0 across the whole case. Each beat starts with `floor(50 × (b + 1) / 16) - floor(50 × b / 16)` calls of the clock `1008:16c2` (`b` = the beat number), and ends with a `state` row.
7. Legs `j` = 0..5. Target spot: `1 + k % 6` when `j = 0`, else `(k + 3j) % 7` (0 = any). Target heading: `(3k + 5j + 1) % 8`. Before leg `j`:
   - `j` odd ("a scene ended"): Johnny's spot = `1 + (k + j) % 6`, heading = `(2k + j) % 8`, set directly, no beat.
   - `j` even and > 0 ("an idle entry"): 8 beats; in the first, a `reset` row (value `j`) and `1018:0074`; in each, `1018:0094`.
8. A leg runs beats until it ends, at most 1500: `1018:0b46(target spot, target heading)`, an `at` row, then `1018:0094` when the answer was 0. The leg ends on an answer of 1. A leg that hits 1500 beats writes a `stuck` row (value `j`, beat = the last beat) and the next leg starts.

| Event | Values |
| --- | --- |
| `sprite` | target, sheet name, index, x, y, flags, clip on (0/1), clip x1, y1, x2, y2 (`1038:0ae4`) |
| `dirty` | source, target, age, x, y, w, h (`1060:007e`, kind 1) |
| `reset` | leg |
| `at` | leg, target spot, target heading, answer (0/1) |
| `stuck` | leg |
| `state` | spot `30e2`, heading `30de`, target spot `30e0`, target heading `30dc`, wanted `30c8`, end heading `30cc`, end spot `30ca` (all signed), route `30d0` as `from,to` or `0`, segment `30ce` as `segment:record` or `0`, frame `30c6` as `segment:record` or `0`, delay `30d4`, random write index `1ce6` |

`segment:record` names a frame list address: `record = (address - list start) / 6`. A turn frame is `turn set:heading`.
